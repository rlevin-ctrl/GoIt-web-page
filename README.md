# YourEnergy — навчальний курсовий проєкт

YourEnergy — це навчальний проєкт, створений у межах курсової роботи з дисципліни “Основи веброзробки (JavaScript)”.  
Сайт присвячений фітнесу та вправам, а головний акцент — на роботі з API, фільтрацією даних, пагінацією, динамічним рендерингом та адаптивною версткою.

---

## 🚀 Функціонал

Сайт дозволяє:

- переглядати вправи за категоріями: **Muscles**, **Body Parts**, **Equipment**
- відкривати списки вправ у вибраній категорії
- переглядати картки вправ з ключовою інформацією (назва, рейтинг, калорії, час, ціль)
- шукати вправи за ключовим словом
- використовувати пагінацію для перемикання сторінок
- переглядати деталі конкретної вправи
